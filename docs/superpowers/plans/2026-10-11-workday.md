# Workday (standup) Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Workday" sidebar tab that shows everything needed for a standup (done since last workday, working on, reviewing, blockers, waiting, not started, with off-sprint work woven in) plus a Copy standup button and a per-day standup note.

**Architecture:** Compose the page client-side. The existing `useDashboard` arrays (openPRs, reviewRequests, reviewingPRs, assignedJiraIssues, jiraIssues) are reused. A new self-fetching hook `useWorkdayExtras` loads five extra pieces (sprint membership, off-sprint tickets, Jira status changes, merged PRs, reviews submitted) only while the tab is mounted. Two pure functions do the work: `buildWorkday` turns the inputs into sections, and `workdayToMarkdown` renders the Slack text. The view itself is thin.

**Tech Stack:** React 18 + TypeScript + Vite, react-bootstrap, @tabler/icons-react, vitest + @testing-library/react. Jira goes through the server proxy (`jiraClient()`), GitHub through client-side GraphQL (`githubGraphql`).

**Spec:** `docs/superpowers/specs/2026-10-11-workday-design.md`

- Off-sprint not-started tickets are limited to those updated in the last **60 days**.
- Weekend default is `[5, 6]` (Fri, Sat) in JS `getDay()` numbering.
- Note type for standup notes is exactly `"standup"`. Its `reference_id` is `standup:YYYY-MM-DD` (local date) and its title is `Standup · Sun 11 Oct`. Badge label "Standup", variant `purple`.
- Match the surrounding code style: short JSDoc on exported functions, comments that say *why*, no new dependencies.

## Deviations from the spec (decided while planning)

- `isConfigured` requires both Jira and GitHub credentials, so a "Jira only missing" state can't occur. When `configured` is false, the whole view shows one "Connect Jira and GitHub in Settings" empty state.
- "Author pushed since your review" on Reviewing rows is dropped (no data for it). Rows show "Review requested" or "Reviewed".
- "Waiting since" uses the PR's opened date, because GitHub search doesn't return review-request timestamps.
- "No reviewer requested" needs requested-reviewer data, so `SEARCH_MY_PRS_QUERY` gains `reviewRequests(first: 10)`, mapped to `GitHubPR.requested_reviewers` (Task 5).
- PR rows open the PR on GitHub in a new tab rather than opening the description modal.

/** "Done since" lookback options on the Workday page. */
export type Lookback = "workday" | "3d" | "7d";

const DAY_NAMES = ["Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"];
const MONTH_NAMES = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];
const pad = (n: number) => String(n).padStart(2, "0");

/** Local midnight `days` days before `d`'s date. */
function midnightDaysAgo(d: Date, days: number): Date {
  return new Date(d.getFullYear(), d.getMonth(), d.getDate() - days);
}

/**
 * Local midnight of the most recent day before `now` that isn't a weekend
 * day. Falls back to yesterday when every day is marked as weekend.
 */
export function lastWorkdayStart(now: Date, weekendDays: number[]): Date {
  for (let back = 1; back <= 7; back++) {
    const day = midnightDaysAgo(now, back);
    if (!weekendDays.includes(day.getDay())) return day;
  }
  return midnightDaysAgo(now, 1);
}

/** Start of the "Done since" window for a lookback option. */
export function sinceFor(lookback: Lookback, now: Date, weekendDays: number[]): Date {
  if (lookback === "3d") return midnightDaysAgo(now, 3);
  if (lookback === "7d") return midnightDaysAgo(now, 7);
  return lastWorkdayStart(now, weekendDays);
}

/** Local YYYY-MM-DD. */
function localDate(d: Date): string {
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
}

/** reference_id of the standup note for `now`'s local day. */
export function standupRef(now: Date): string {
  return `standup:${localDate(now)}`;
}

/** e.g. "Thu 8 Oct". */
export function formatSinceLabel(d: Date): string {
  return `${DAY_NAMES[d.getDay()]} ${d.getDate()} ${MONTH_NAMES[d.getMonth()]}`;
}

/** Title of the standup note for `now`'s local day, e.g. "Standup · Sun 11 Oct". */
export function standupTitle(now: Date): string {
  return `Standup · ${formatSinceLabel(now)}`;
}

/** JQL date literal "yyyy-MM-dd HH:mm" in local time. */
export function formatJqlDate(d: Date): string {
  return `${localDate(d)} ${pad(d.getHours())}:${pad(d.getMinutes())}`;
}

import { jiraClient } from "../http";
import type { DoneTicket, OffSprintTicket, SprintTicket, StatusCategoryKey } from "../../types";
import { formatJqlDate } from "../../views/workday/dates";
import {
  BASE_ISSUE_FIELDS,
  FLAGGED_FIELD,
  SPRINT_FIELD,
  STORY_POINTS_FIELD,
  getMyself,
  mapIssue,
} from "./issues";

/** Upper bound on off-sprint tickets fetched across pages. */
const MAX_OFF_SPRINT = 200;
/** Upper bound on "done since" tickets. */
const MAX_DONE = 50;

const isFlagged = (f: any): boolean => Array.isArray(f[FLAGGED_FIELD]) && f[FLAGGED_FIELD].length > 0;

/** Active sprint's name, else the first non-closed one, else null. */
function sprintNameOf(f: any): string | null {
  const sprints: any[] = Array.isArray(f[SPRINT_FIELD]) ? f[SPRINT_FIELD] : [];
  const active = sprints.find((s) => s?.state === "active");
  const open = active ?? sprints.find((s) => s?.state !== "closed");
  return open?.name ?? null;
}

/** Assigned, not-done tickets in any open sprint, with sprint name / points / flagged. */
export async function getSprintTickets(signal?: AbortSignal): Promise<{ tickets: SprintTicket[] }> {
  const jql = "assignee = currentUser() AND sprint in openSprints() AND statusCategory != Done";
  const fields = ["summary", "status", SPRINT_FIELD, STORY_POINTS_FIELD, FLAGGED_FIELD];
  const { data } = await jiraClient().post("/search/jql", { jql, fields, maxResults: 100 }, { signal });
  const tickets = (data.issues || []).map((issue: any): SprintTicket => {
    const f = issue.fields ?? {};
    return {
      key: issue.key,
      summary: f.summary ?? "",
      status: {
        name: f.status?.name ?? "",
        categoryKey: (f.status?.statusCategory?.key ?? "new") as StatusCategoryKey,
      },
      sprintName: sprintNameOf(f),
      points: typeof f[STORY_POINTS_FIELD] === "number" ? f[STORY_POINTS_FIELD] : null,
      flagged: isFlagged(f),
    };
  });
  return { tickets };
}

/**
 * Assigned, unresolved tickets outside every open sprint, updated in the last
 * 60 days. Feeds the Off-sprint indicator, not a section of its own.
 */
export async function getOffSprintTickets(
  signal?: AbortSignal,
): Promise<{ issues: OffSprintTicket[] }> {
  const jira = jiraClient();
  const jql =
    "assignee = currentUser() AND resolution = Unresolved AND (sprint is EMPTY OR sprint not in openSprints()) AND updated >= -60d ORDER BY updated DESC";
  const raw: any[] = [];
  let nextPageToken: string | undefined;
  do {
    const payload: Record<string, any> = {
      jql,
      fields: [...BASE_ISSUE_FIELDS, FLAGGED_FIELD],
      maxResults: 100,
    };
    if (nextPageToken) payload.nextPageToken = nextPageToken;
    const { data } = await jira.post("/search/jql", payload, { signal });
    raw.push(...(data.issues || []));
    nextPageToken = data.nextPageToken || undefined;
  } while (nextPageToken && raw.length < MAX_OFF_SPRINT);

  return {
    issues: raw
      .slice(0, MAX_OFF_SPRINT)
      .map((issue) => ({ ...mapIssue(issue), flagged: isFlagged(issue.fields ?? {}) })),
  };
}

/**
 * Tickets whose status the current user changed after `since`, with the latest
 * such change. Histories by other people are ignored when the current user can
 * be resolved; otherwise JQL's CHANGED BY is trusted.
 */
export async function getDoneSince(
  since: Date,
  signal?: AbortSignal,
): Promise<{ tickets: DoneTicket[] }> {
  const jql = `status CHANGED BY currentUser() AFTER "${formatJqlDate(since)}" ORDER BY updated DESC`;
  const { data } = await jiraClient().post(
    "/search/jql",
    { jql, fields: ["summary"], expand: "changelog", maxResults: MAX_DONE },
    { signal },
  );
  const issues: any[] = data.issues || [];
  const me = issues.length > 0 ? await getMyself() : null;
  const sinceMs = since.getTime();

  const tickets: DoneTicket[] = [];
  for (const issue of issues) {
    let latest: { at: number; created: string; to: string } | null = null;
    for (const h of issue.changelog?.histories || []) {
      if (me && h.author?.accountId !== me.accountId) continue;
      const at = new Date(h.created).getTime();
      if (Number.isNaN(at) || at < sinceMs) continue;
      const item = (h.items || []).find((i: any) => i.field === "status");
      if (!item) continue;
      if (!latest || at > latest.at) latest = { at, created: h.created, to: item.toString ?? "" };
    }
    if (latest) {
      tickets.push({
        key: issue.key,
        summary: issue.fields?.summary ?? "",
        toStatus: latest.to,
        changedAt: latest.created,
      });
    }
  }
  return { tickets };
}

/** Upper bound on reviewed PRs considered for Workday "Done since". */
const MAX_REVIEWED = 50;
const REVIEW_STATES: ReadonlySet<string> = new Set(["APPROVED", "CHANGES_REQUESTED", "COMMENTED"]);

/**
 * Others' PRs the viewer reviewed since `since`, with the viewer's latest
 * submitted review in that window. Pending and dismissed reviews are skipped.
 */
export async function getReviewedSince(since: Date): Promise<{ reviews: ReviewedPR[] }> {
  const { githubUsername: user } = requireSettings();
  const query = `reviewed-by:${user} -author:${user} type:pr updated:>=${since.toISOString().slice(0, 10)}`;
  const result = await githubGraphql<{ search: { nodes: any[] } }>(REVIEWED_SINCE_QUERY, {
    query,
    first: MAX_REVIEWED,
  });
  const sinceMs = since.getTime();
  const me = user.toLowerCase();
  const reviews: ReviewedPR[] = [];
  for (const node of result.search.nodes || []) {
    let latest: { at: number; state: ReviewState; submittedAt: string } | null = null;
    for (const r of node.reviews?.nodes || []) {
      if ((r.author?.login || "").toLowerCase() !== me || !REVIEW_STATES.has(r.state)) continue;
      const at = new Date(r.submittedAt).getTime();
      if (Number.isNaN(at) || at < sinceMs) continue;
      if (!latest || at > latest.at) latest = { at, state: r.state, submittedAt: r.submittedAt };
    }
    if (latest) {
      reviews.push({ pr: mapGraphQLPr(node), state: latest.state, submittedAt: latest.submittedAt });
    }
  }
  return { reviews };
}

import { getDoneSince, getOffSprintTickets, getSprintTickets } from "../api/jira/workday";
import { getMergedPrs, getReviewedSince } from "../api/github";

/** One independently-fetched piece: data and error are both null while loading. */
export interface Part<T> {
  data: T | null;
  error: string | null;
}

/** The Workday page's own data, on top of the shared dashboard sources. */
export interface WorkdayExtras {
  sprint: Part<SprintTicket[]>;
  offSprint: Part<OffSprintTicket[]>;
  doneTickets: Part<DoneTicket[]>;
  merged: Part<GitHubPR[]>;
  reviewed: Part<ReviewedPR[]>;
}

const LOADING = { data: null, error: null };

export const EMPTY_EXTRAS: WorkdayExtras = {
  sprint: LOADING,
  offSprint: LOADING,
  doneTickets: LOADING,
  merged: LOADING,
  reviewed: LOADING,
};

/** Settle one request into a Part so a failure stays local to its section. */
async function part<T>(load: () => Promise<T>): Promise<Part<T>> {
  try {
    return { data: await load(), error: null };
  } catch (err: any) {
    return { data: null, error: err?.message || String(err) };
  }
}

/** Sprint membership and off-sprint tickets; independent of the lookback. */
export async function fetchWorkdayStable(
  signal?: AbortSignal,
): Promise<Pick<WorkdayExtras, "sprint" | "offSprint">> {
  const [sprint, offSprint] = await Promise.all([
    part(async () => (await getSprintTickets(signal)).tickets),
    part(async () => (await getOffSprintTickets(signal)).issues),
  ]);
  return { sprint, offSprint };
}

/** "Done since" pieces; refetched when the lookback changes. */
export async function fetchWorkdaySince(
  since: Date,
  signal?: AbortSignal,
): Promise<Pick<WorkdayExtras, "doneTickets" | "merged" | "reviewed">> {
  const [doneTickets, merged, reviewed] = await Promise.all([
    part(async () => (await getDoneSince(since, signal)).tickets),
    part(async () => (await getMergedPrs({ scope: "user", since })).prs as GitHubPR[]),
    part(async () => (await getReviewedSince(since)).reviews),
  ]);
  return { doneTickets, merged, reviewed };
}

import {
  EMPTY_EXTRAS,
  fetchWorkdaySince,
  fetchWorkdayStable,
  type WorkdayExtras,

/**
 * Workday-only data, fetched while the Workday tab is mounted (lazy, like the
 * other self-fetching views). Gated on `configured` so it doesn't race the
 * credentials load; refetches when `refreshKey` bumps. Sprint data doesn't
 * depend on the lookback, so changing `since` only refetches the "done" parts.
 */
export function useWorkdayExtras(
  configured: boolean,
  since: Date,
  refreshKey: number,
): WorkdayExtras {
  const [extras, setExtras] = useState<WorkdayExtras>(EMPTY_EXTRAS);
  const sinceMs = since.getTime();

  useEffect(() => {
    if (!configured) return;
    const ctrl = new AbortController();
    setExtras((prev) => ({ ...prev, sprint: EMPTY_EXTRAS.sprint, offSprint: EMPTY_EXTRAS.offSprint }));
    fetchWorkdayStable(ctrl.signal).then((res) => {
      if (!ctrl.signal.aborted) setExtras((prev) => ({ ...prev, ...res }));
    });
    return () => ctrl.abort();
  }, [configured, refreshKey]);

  useEffect(() => {
    if (!configured) return;
    const ctrl = new AbortController();
    setExtras((prev) => ({
      ...prev,
      doneTickets: EMPTY_EXTRAS.doneTickets,
      merged: EMPTY_EXTRAS.merged,
      reviewed: EMPTY_EXTRAS.reviewed,
    }));
    fetchWorkdaySince(new Date(sinceMs), ctrl.signal).then((res) => {
      if (!ctrl.signal.aborted) setExtras((prev) => ({ ...prev, ...res }));
    });
    return () => ctrl.abort();
  }, [configured, sinceMs, refreshKey]);

  return extras;
}

**Rules (the tests encode them):**
- **Assigned set** = `assignedIssues` ∪ `extras.offSprint.data` (dedupe by key; the assignedIssues entry wins).
- **Off-sprint key** = in the assigned set AND `extras.sprint.data` is loaded AND the key is not in the sprint data. If sprint data is null (loading or error), nothing is off-sprint.
- `statusCategoryOf`: use `status.statusCategory.key` when present. Otherwise derive from the colour: `"yellow"` → indeterminate, `"green"` → done, anything else → new.
- **Ticket lookup** for summaries and statuses: `allIssues` ∪ assigned set ∪ sprint tickets.
- **Working on:**
  - `groupByTicket(openPRs)`, mapped to `TicketGroup`s.
  - Then add assigned tickets in category `indeterminate` that have no open PR (prs `[]`), in assignedIssues order.
  - The "No ticket" group goes last.
  - `loading` = `false` (dashboard arrays are already loaded when the tab renders; App passes them).
- **Reviewing:**
  - `reviewRequests` ∪ `reviewingPRs`, deduped by `html_url` (reviewRequests first), then `groupByTicket`.
  - Ticket refs always have `offSprint: false`.
  - `reviewRequestedUrls` = set of reviewRequests urls.
- **Blockers:**
  - For each non-draft open PR where `categorizeOpenPR(pr) === "needs-action"`, collect the labels of the `ACTIONABLE_REASONS` with keys `ci_failed`, `conflict`, `changes_requested`, `reviewed` that match. Emit `{kind:"pr", reasons}` when there's at least one.
  - Else, if `categorizeOpenPR(pr) === "pending"` and `pr.requested_reviewers` is an empty array and `!pr.review_status`, emit reasons `["No reviewer requested"]`.
  - Then, for each assigned ticket flagged in the sprint data or the offSprint data, emit `{kind:"flagged"}`.
  - Errors come from `extras.sprint.error` (flag data). `loading` is true while sprint data is loading.
- **Waiting:**
  - For each non-draft open PR with `categorizeOpenPR === "pending"` and `requested_reviewers` not an empty array, emit `{kind:"awaiting-review", reviewers: pr.requested_reviewers ?? [], since: pr.created_at}`.
  - For each open PR with `review_status === "APPROVED" && !in_merge_queue && !draft` that isn't needs-action, emit `{kind:"your-move"}`.
  - For each assigned ticket whose status name matches `/code review/i` and that has `codeReviewers` non-empty, emit `{kind:"code-review", reviewers: names}`.
- **Done:**
  - Merged → `{kind:"merged", at: pr.merged_at}`.
  - Reviewed → `{kind:"reviewed", at: submittedAt}`.
  - doneTickets → `{kind:"status", at: changedAt}`.
  - Sorted by `at` descending.
  - `loading` = any of the three parts loading. `error` = the non-null errors joined with `"; "`.
- **Not started:**
  - Assigned tickets with category `new` whose key has no open PR.
  - Sprint ones go in `items`, ordered as the sprint data, with sprintName/points. When sprint data isn't loaded yet, treat every new ticket as a sprint ticket with null sprint info.
  - Off-sprint ones go in `offSprintItems`, but only if `updated` ≥ now − 60 days, sorted by updated descending.
  - `loading`/`error` come from the sprint part.
- **offSprintCount**: distinct keys with `offSprint` true across workingOn, blockers, waiting and notStarted.offSprintItems.
- **filterWorkday:**
  - `"all"` returns the input unchanged.
  - Otherwise each list item is kept by `isOff(item) = item.ticket?.offSprint === true`. `"sprint"` keeps `!isOff`, so no-ticket PRs stay. `"off"` keeps `isOff`, so the reviewing list empties and no-ticket PRs drop.
  - Items without a `ticket` property (none currently) count as not-off.
  - `notStarted.offSprintItems` is cleared under `"sprint"`. Under `"off"`, `notStarted.items` is cleared.
  - `offSprintCount` is unchanged.

  const assigned = new Map<string, JiraIssue>();
  for (const i of inp.assignedIssues) assigned.set(i.key.toUpperCase(), i);
  for (const i of extras.offSprint.data ?? []) {
    if (!assigned.has(i.key.toUpperCase())) assigned.set(i.key.toUpperCase(), i);
  }

  const sprintData = extras.sprint.data;
  const sprintByKey = new Map((sprintData ?? []).map((t) => [t.key.toUpperCase(), t]));
  const isOffSprint = (key: string) =>
    sprintData !== null && assigned.has(key.toUpperCase()) && !sprintByKey.has(key.toUpperCase());

  const lookup = new Map<string, { summary: string; statusName: string | null }>();
  for (const t of sprintData ?? []) lookup.set(t.key.toUpperCase(), { summary: t.summary, statusName: t.status.name });
  for (const i of [...assigned.values(), ...inp.allIssues]) {
    lookup.set(i.key.toUpperCase(), { summary: i.summary, statusName: i.status?.name ?? null });
  }

  const ref = (key: string, flaggable = true): TicketRef => {
    const info = lookup.get(key.toUpperCase());
    return {
      key,
      summary: info?.summary ?? "",
      statusName: info?.statusName ?? null,
      offSprint: flaggable && isOffSprint(key),
    };
  };
  const prRef = (pr: GitHubPR, flaggable = true) => {
    const key = ticketKeyOf(pr);
    return key ? ref(key, flaggable) : null;
  };

  const prTicketKeys = new Set(
    inp.openPRs.map(ticketKeyOf).filter((k): k is string => !!k).map((k) => k.toUpperCase()),
  );

  // Working on: my PRs grouped by ticket, then in-progress tickets with no PR, then "No ticket".
  const prGroups = groupByTicket(inp.openPRs);
  const workingOn: TicketGroup[] = prGroups
    .filter((g) => g.ticket !== null)
    .map((g) => ({ ticket: ref(g.ticket!), prs: g.prs }));
  for (const issue of assigned.values()) {
    if (statusCategoryOf(issue) === "indeterminate" && !prTicketKeys.has(issue.key.toUpperCase())) {
      workingOn.push({ ticket: ref(issue.key), prs: [] });
    }
  }
  const noTicket = prGroups.filter((g) => g.ticket === null).flatMap((g) => g.prs);
  if (noTicket.length > 0) workingOn.push({ ticket: null, prs: noTicket });

  // Reviewing: requested ∪ reviewing, deduped by URL; never off-sprint.
  const seen = new Set<string>();
  const reviewPRs = [...inp.reviewRequests, ...inp.reviewingPRs].filter((p) => {
    if (seen.has(p.html_url)) return false;
    seen.add(p.html_url);
    return true;
  });
  const reviewing: TicketGroup[] = groupByTicket(reviewPRs).map((g) => ({
    ticket: g.ticket ? ref(g.ticket, false) : null,
    prs: g.prs,
  }));

  // Blockers and waiting.
  const blockers: BlockerItem[] = [];
  const waiting: WaitingItem[] = [];
  for (const pr of inp.openPRs) {
    if (pr.draft) continue;
    const category = categorizeOpenPR(pr);
    const ticket = prRef(pr);
    if (category === "needs-action") {
      const reasons = ACTIONABLE_REASONS.filter((r) => BLOCKER_REASON_KEYS.has(r.key) && r.matches(pr)).map(
        (r) => r.label,
      );
      if (reasons.length > 0) blockers.push({ kind: "pr", pr, ticket, reasons });
      continue;
    }
    if (category === "pending") {
      if (Array.isArray(pr.requested_reviewers) && pr.requested_reviewers.length === 0 && !pr.review_status) {
        blockers.push({ kind: "pr", pr, ticket, reasons: ["No reviewer requested"] });
      } else {
        waiting.push({
          kind: "awaiting-review",
          pr,
          ticket,
          reviewers: pr.requested_reviewers ?? [],
          since: pr.created_at,
        });
      }
      continue;
    }
    if (pr.review_status === "APPROVED" && !pr.in_merge_queue) {
      waiting.push({ kind: "your-move", pr, ticket });
    }
  }
  const flaggedKeys = new Set<string>();
  for (const t of sprintData ?? []) if (t.flagged) flaggedKeys.add(t.key.toUpperCase());
  for (const t of extras.offSprint.data ?? []) if (t.flagged) flaggedKeys.add(t.key.toUpperCase());
  for (const issue of assigned.values()) {
    if (flaggedKeys.has(issue.key.toUpperCase())) blockers.push({ kind: "flagged", ticket: ref(issue.key) });
  }
  for (const issue of assigned.values()) {
    const reviewers = (issue.codeReviewers ?? []).map((r) => r.displayName).filter(Boolean);
    if (/code review/i.test(issue.status?.name ?? "") && reviewers.length > 0) {
      waiting.push({ kind: "code-review", ticket: ref(issue.key), reviewers });
    }
  }

  // Done since.
  const done: DoneItem[] = [
    ...(extras.merged.data ?? []).map((pr): DoneItem => ({ kind: "merged", pr, ticket: prRef(pr), at: pr.merged_at ?? pr.updated_at })),
    ...(extras.reviewed.data ?? []).map((r): DoneItem => ({ kind: "reviewed", pr: r.pr, ticket: prRef(r.pr, false), state: r.state, at: r.submittedAt })),
    ...(extras.doneTickets.data ?? []).map((t): DoneItem => {
      if (!lookup.has(t.key.toUpperCase())) lookup.set(t.key.toUpperCase(), { summary: t.summary, statusName: t.toStatus });
      return { kind: "status", ticket: ref(t.key), toStatus: t.toStatus, at: t.changedAt };
    }),
  ].sort((a, b) => new Date(b.at).getTime() - new Date(a.at).getTime());
  const doneParts = [extras.merged, extras.reviewed, extras.doneTickets];

  // Not started.
  const notStartedSprint: NotStartedItem[] = [];
  const notStartedOff: NotStartedItem[] = [];
  const cutoff = now.getTime() - OFF_SPRINT_WINDOW_MS;
  const newIssues = [...assigned.values()].filter(
    (i) => statusCategoryOf(i) === "new" && !prTicketKeys.has(i.key.toUpperCase()),
  );
  for (const issue of newIssues) {
    const sprint = sprintByKey.get(issue.key.toUpperCase());
    const item: NotStartedItem = {
      ticket: ref(issue.key),
      sprintName: sprint?.sprintName ?? null,
      points: sprint?.points ?? null,
      updated: issue.updated ?? null,
    };
    if (!item.ticket.offSprint) notStartedSprint.push(item);
    else if (issue.updated && new Date(issue.updated).getTime() >= cutoff) notStartedOff.push(item);
  }
  if (sprintData) {
    const order = new Map(sprintData.map((t, idx) => [t.key.toUpperCase(), idx]));
    notStartedSprint.sort((a, b) => (order.get(a.ticket.key.toUpperCase()) ?? 0) - (order.get(b.ticket.key.toUpperCase()) ?? 0));
  }
  notStartedOff.sort((a, b) => new Date(b.updated ?? 0).getTime() - new Date(a.updated ?? 0).getTime());

  const offKeys = new Set<string>();
  const noteOff = (t: TicketRef | null) => t?.offSprint && offKeys.add(t.key.toUpperCase());
  workingOn.forEach((g) => noteOff(g.ticket));
  blockers.forEach((b) => noteOff(b.ticket));
  waiting.forEach((w) => noteOff(w.ticket));
  notStartedOff.forEach((n) => noteOff(n.ticket));

  return {
    done: {
      items: done,
      loading: doneParts.some(isLoading),
      error: doneParts.map((p) => p.error).filter(Boolean).join("; ") || null,
    },
    workingOn: { items: workingOn, loading: false, error: null },
    reviewing: { items: reviewing, loading: false, error: null },
    reviewRequestedUrls: new Set(inp.reviewRequests.map((p) => p.html_url)),
    blockers: { items: blockers, loading: isLoading(extras.sprint), error: extras.sprint.error },
    waiting: { items: waiting, loading: false, error: null },
    notStarted: {
      items: notStartedSprint,
      offSprintItems: notStartedOff,
      loading: isLoading(extras.sprint),
      error: extras.sprint.error,
    },
    offSprintCount: offKeys.size,
  };
}

/** Apply the header's sprint filter. "all" returns the same object. */
export function filterWorkday(s: WorkdaySections, filter: SprintFilter): WorkdaySections {
  if (filter === "all") return s;
  const keep = (item: { ticket?: TicketRef | null }) =>
    filter === "sprint" ? item.ticket?.offSprint !== true : item.ticket?.offSprint === true;
  return {
    ...s,
    done: { ...s.done, items: s.done.items.filter(keep) },
    workingOn: { ...s.workingOn, items: s.workingOn.items.filter(keep) },
    reviewing: { ...s.reviewing, items: s.reviewing.items.filter(keep) },
    blockers: { ...s.blockers, items: s.blockers.items.filter(keep) },
    waiting: { ...s.waiting, items: s.waiting.items.filter(keep) },
    notStarted: {
      ...s.notStarted,
      items: filter === "off" ? [] : s.notStarted.items,
      offSprintItems: filter === "sprint" ? [] : s.notStarted.offSprintItems,
    },
  };
}

**Files:**

**Interfaces:**
- Consumes: `WorkdaySections`, `TicketRef`, and the item types from Task 7.
- Produces: `workdayToMarkdown(s: WorkdaySections, noteContent: string, now: Date): string`

**Format rules:**
- **Headings:** `*Yesterday*`, `*Today*` and `*Blockers*`, separated by a blank line. Bullets use `• `. A heading with no lines is omitted. Empty everything → `""`.
- **Yesterday** (from `done`, in order):
  - `merged` → `Merged {KEY }{title} (#{n})`.
  - `status` → `Moved {KEY} to {toStatus}`.
  - All `reviewed` items collapse into one line placed where the first one occurred: `Reviewed {label} ({approved|changes requested|commented}), …`. The label is the ticket key, else `{repo short name}#{n}`.
- **Blockers** come before Today for dedup purposes but print last:
  - Blocker `pr` → `{label} #{n} {reasons joined ", " lower-cased}`. The label is the ticket key, else the PR title.
  - Blocker `flagged` → `{KEY} flagged in Jira`.
  - Waiting `awaiting-review` → `{label} #{n} waiting on review[ from {reviewers joined ", "}] ({age})`.
  - Waiting `your-move` → `{label} #{n} approved, ready to merge`.
  - Waiting `code-review` → `{KEY} in Code Review with {reviewers}`.
  - Then each non-empty line of `noteContent`, trimmed, with a leading `- `, `* ` or `• ` stripped.
  - PR lines are deduped by URL and ticket lines by key.
  - `age`: whole days if ≥ 24h (e.g. `2d`), else hours (e.g. `5h`), minimum `1h`.
- **Today:**
  - Each workingOn group with a ticket: drop PRs already in Blockers. If the group had PRs and none remain, skip it. If the group had no PRs and its key is in Blockers, skip it.
  - Line: `{KEY} {summary} — #{n} {draft ? "draft" : "in review"}, …`. With no PRs: `{KEY} {summary} (no PR yet)`.
  - The "No ticket" group gives one line per remaining PR: `{title} (#{n})`.
  - Then one line `Reviewing {labels joined ", "}`, using unique labels (ticket key, else `{repo short}#{n}`), if there are any.
- **Off-sprint suffix:** `(off-sprint)` goes after the line. When the line already ends in `(no PR yet)`, it becomes `(off-sprint, no PR yet)`.
- Not-started is never included.

import type { GitHubPR, ReviewState } from "../../types";
import type { TicketRef, WorkdaySections } from "./types";

const REVIEW_WORD: Record<ReviewState, string> = {
  APPROVED: "approved",
  CHANGES_REQUESTED: "changes requested",
  COMMENTED: "commented",
};

/** "2d" / "5h" since `iso`. */
function shortAge(iso: string, now: Date): string {
  const hours = Math.max(1, Math.floor((now.getTime() - new Date(iso).getTime()) / 3_600_000));
  return hours >= 24 ? `${Math.floor(hours / 24)}d` : `${hours}h`;
}

/** "app#12": repo short name + number, for PRs with no ticket. */
const repoRef = (pr: GitHubPR) => `${pr.repo_full_name.split("/").pop()}#${pr.number}`;

/** Append the off-sprint marker, merging it into a trailing "(no PR yet)". */
function offSprint(line: string, ticket: TicketRef | null): string {
  if (!ticket?.offSprint) return line;
  if (line.endsWith(" (no PR yet)")) return line.replace(/ \(no PR yet\)$/, " (off-sprint, no PR yet)");
  return `${line} (off-sprint)`;
}

/**
 * Slack-ready standup text: *Yesterday* (done), *Today* (working on +
 * reviewing) and *Blockers* (blockers + waiting + note lines). Each PR/ticket
 * appears once, Blockers taking priority over Today; empty headings are dropped.
 */
export function workdayToMarkdown(s: WorkdaySections, noteContent: string, now: Date): string {
  // Yesterday
  const yesterday: string[] = [];
  const reviewed: string[] = [];
  let reviewedAt = -1;
  for (const item of s.done.items) {
    if (item.kind === "merged") {
      const key = item.ticket ? `${item.ticket.key} ` : "";
      yesterday.push(offSprint(`Merged ${key}${item.pr.title} (#${item.pr.number})`, item.ticket));
    } else if (item.kind === "status") {
      yesterday.push(offSprint(`Moved ${item.ticket.key} to ${item.toStatus}`, item.ticket));
    } else {
      if (reviewedAt < 0) {
        reviewedAt = yesterday.length;
        yesterday.push("");
      }
      reviewed.push(`${item.ticket?.key ?? repoRef(item.pr)} (${REVIEW_WORD[item.state]})`);
    }
  }
  if (reviewedAt >= 0) yesterday[reviewedAt] = `Reviewed ${reviewed.join(", ")}`;

  // Blockers (computed first so Today can skip what's here)
  const blockers: string[] = [];
  const blockedPRs = new Set<string>();
  const blockedKeys = new Set<string>();
  const label = (pr: GitHubPR, ticket: TicketRef | null) => ticket?.key ?? pr.title;
  const addPR = (pr: GitHubPR, ticket: TicketRef | null, text: string) => {
    if (blockedPRs.has(pr.html_url)) return;
    blockedPRs.add(pr.html_url);
    blockers.push(offSprint(text, ticket));
  };
  const addTicket = (ticket: TicketRef, text: string) => {
    if (blockedKeys.has(ticket.key)) return;
    blockedKeys.add(ticket.key);
    blockers.push(offSprint(text, ticket));
  };
  for (const b of s.blockers.items) {
    if (b.kind === "flagged") addTicket(b.ticket, `${b.ticket.key} flagged in Jira`);
    else addPR(b.pr, b.ticket, `${label(b.pr, b.ticket)} #${b.pr.number} ${b.reasons.join(", ").toLowerCase()}`);
  }
  for (const w of s.waiting.items) {
    if (w.kind === "code-review") {
      addTicket(w.ticket, `${w.ticket.key} in Code Review with ${w.reviewers.join(", ")}`);
    } else if (w.kind === "your-move") {
      addPR(w.pr, w.ticket, `${label(w.pr, w.ticket)} #${w.pr.number} approved, ready to merge`);
    } else {
      const from = w.reviewers.length > 0 ? ` from ${w.reviewers.join(", ")}` : "";
      addPR(w.pr, w.ticket, `${label(w.pr, w.ticket)} #${w.pr.number} waiting on review${from} (${shortAge(w.since, now)})`);
    }
  }
  for (const raw of noteContent.split("\n")) {
    const line = raw.trim().replace(/^([-*•])\s+/, "");
    if (line) blockers.push(line);
  }

  // Today
  const today: string[] = [];
  for (const g of s.workingOn.items) {
    const prs = g.prs.filter((p) => !blockedPRs.has(p.html_url));
    if (g.ticket === null) {
      for (const p of prs) today.push(`${p.title} (#${p.number})`);
      continue;
    }
    if (g.prs.length > 0 && prs.length === 0) continue;
    if (g.prs.length === 0 && blockedKeys.has(g.ticket.key)) continue;
    const head = `${g.ticket.key} ${g.ticket.summary}`.trim();
    const line =
      prs.length === 0
        ? `${head} (no PR yet)`
        : `${head} — ${prs.map((p) => `#${p.number} ${p.draft ? "draft" : "in review"}`).join(", ")}`;
    today.push(offSprint(line, g.ticket));
  }
  const reviewLabels = [
    ...new Set(s.reviewing.items.flatMap((g) => (g.ticket ? [g.ticket.key] : g.prs.map(repoRef)))),
  ];
  if (reviewLabels.length > 0) today.push(`Reviewing ${reviewLabels.join(", ")}`);

  const block = (title: string, lines: string[]) =>
    lines.length === 0 ? null : [`*${title}*`, ...lines.map((l) => `• ${l}`)].join("\n");
  return [block("Yesterday", yesterday), block("Today", today), block("Blockers", blockers)]
    .filter((b): b is string => b !== null)
    .join("\n\n");
}

**UI spec (follow the mockup `.superpowers/brainstorm/5861-1791656252/content/workday-v2.html` if it exists; otherwise this text):**

- **Layout:** `.workday` is a CSS grid with `grid-template-columns: minmax(0, 1fr) 320px; gap: 16px`. Below 1100px it becomes one column. The left column holds the sections; the right column is sticky and holds Notes and Copy preview.
- **Header** (`.workday-header`):
  - `<h5>Workday</h5>`, a date pill (`formatSinceLabel(now)`), and the subtitle `Since {formatSinceLabel(since)}`.
  - Filter chips are buttons with `aria-pressed`: "All", "Sprint only", "Off-sprint · {N}". The value is persisted in localStorage `dev-home-workday-filter`.
  - A "Refresh" button (calls `onRefresh`) and a primary "Copy standup" button.
- **Section order and titles** (`WorkdaySection` takes `title`, `count`, `loading`, `error`, `empty`, `actions?`, `children`):
  1. "Done since last workday". Its actions are the lookback segmented buttons "Last workday" / "3 days" / "7 days", persisted in localStorage `dev-home-workday-lookback`. Rows show a pill ("Merged" success, "Approved" success, "Changes requested" danger, "Commented" neutral, "To {status}" info), then a ticket chip if there is one, the title, and a relative time.
  2. "Working on": `<TicketGroupList groups={...} fields={MY_PR_FIELDS} />`.
  3. "Reviewing": TicketGroupList with review fields. Each row is suffixed with a tiny label "Review requested" when its url is in `reviewRequestedUrls`, else "Reviewed".
  4. "Blockers / needs attention". PR rows show reasons as danger/warning pills. Flagged rows show a "Flagged" danger pill, the ticket chip and the summary.
  5. "Waiting on others". Awaiting-review rows show "Waiting on {reviewers or 'review'} · {age}". your-move rows show "Approved — your move". Code-review rows show "Code Review · {reviewers}".
  6. "Assigned, not started". Sprint rows show the ticket chip, summary, sprint name and "{points} pts". Then, if there are any off-sprint items, a muted divider "Off-sprint", the first 3 rows plus a "Show {n} more" button toggling the rest. Off-sprint rows show `updated {relative}`.
- **Section states:**
  - `loading && items.length === 0`: three `.workday-skeleton` bars.
  - `error`: an inline `.workday-section-error` text line, still rendering any items.
  - Empty and not loading: a muted one-line `empty` text, e.g. "Nothing merged, reviewed or moved since {since}".
  - The count badge shows `items.length`.
- **TicketGroupList** (always renders a header per ticket group, unlike PRTable which only clusters multi-PR tickets):
  - The header row uses classes `pr-cluster-header workday-group-header` and contains the exported `TicketChip`, the summary (`pr-cluster-summary`), a status pill (`statusName`), and the PR count (`pr-cluster-count`).
  - Off-sprint tickets get `<span className="workday-pill workday-pill--offsprint">Off-sprint</span>`, styled with `border: 1px dashed var(--color-status-warning, #d29922); color: var(--color-status-warning, #d29922);`.
  - Groups with `prs.length === 0` show `<span className="workday-pill workday-pill--nopr">No PR yet</span>` (dashed muted border) and no rows.
  - The `ticket === null` group header reads "No ticket".
  - PR rows: `<PRCard pr fields jiraBaseUrl clustered onOpen={(p) => window.open(p.html_url, "_blank", "noopener,noreferrer")} />`.
  - `MY_PR_FIELDS = { showAuthor: false, showBranch: true, showStatus: true, showChecks: true, timestamps: "open" }`. Review fields are the same but with `showAuthor: true, showBranch: false, showStatus: false`.
- **StandupNotes** (props: `now`, `notes`, `addNote`, `editNote`, `onChange(content)`):
  - Finds `notes.find(n => n.type === "standup" && n.reference_id === standupRef(now))`.
  - Local `text` state initialises from the note's content. When the note first appears (e.g. notes finished loading), it syncs the text once, but only if the user hasn't typed yet.
  - On change, it sets the text, calls `onChange`, and runs a 600ms debounced save:
    - If no note exists and nothing is being created, set `creatingRef = true` and `await addNote("standup", text, standupRef(now), standupTitle(now))`. Store the returned note id in a ref.
    - Else, `editNote(id, { content: latestText })`.
    - Keystrokes while a create is in flight just update `latestRef`. When the create resolves, if `latestRef.current !== createdContent`, call `editNote` once more.
    - On unmount, flush a pending debounce.
  - Renders a Card titled "Notes for today", a `<textarea className="form-control" rows={6} placeholder="Anything to raise at standup? Each line becomes a Blockers bullet.">`, and a muted hint "Saved to Notes as “{standupTitle(now)}”".
- **Copy preview:** a Card titled "Copy preview" holding `<pre className="workday-preview">{markdown || "Nothing to report yet."}</pre>`, where `markdown = workdayToMarkdown(filtered, noteText, now)`. The preview uses the filtered sections, so "Sprint only" copies sprint work only.
- **Copy:** `navigator.clipboard.writeText(markdown)`, then `toast.show("Standup copied")`. On failure, `toast.show("Couldn't copy to clipboard")`. Render `<Toast message visible />` once at the bottom of the view.
- **Not configured:** `if (!configured)` return `<EmptyState icon={<IconSun size={40} stroke={1.5} />} title="Connect Jira and GitHub" description="Add your credentials in Settings to see your workday." />`.
- **`now`:** `const now = useMemo(() => props.now ?? new Date(), [props.now, refreshKey])`, so a refresh recomputes "since".
- **Done section loading:** pass `sections.done.loading`. Working on / Reviewing / Waiting use the `loading` prop.

function useStoredState<T extends string>(key: string, initial: T, allowed: readonly T[]) {
  const [value, setValue] = useState<T>(() => {
    const v = localStorage.getItem(key) as T | null;
    return v && allowed.includes(v) ? v : initial;
  });
  const set = useCallback((v: T) => {
    localStorage.setItem(key, v);
    setValue(v);
  }, [key]);
  return [value, set] as const;
}
